# Logos des partenaires et médias

Déposez ici les logos officiels (SVG de préférence, sinon PNG/WebP transparent, 400 px de large minimum),
obtenus auprès de chaque partenaire avec son accord d'utilisation.

Puis indiquez le nom du fichier dans `src/data/partners.js` :

```js
'crtv': 'crtv.svg',
```

Sans fichier, le site affiche un monogramme aux couleurs des JCIA, toujours accompagné du nom.
